# Documentación — Gestor Documental Jurídico

## Descripción general

**Gestor Documental Jurídico (SGDJ)** es una aplicación web para la gestión integral de documentos jurídicos, clientes, procesos y usuarios. El sistema permite registrar, buscar, modificar y dar seguimiento a documentos legales dentro de un entorno controlado.
